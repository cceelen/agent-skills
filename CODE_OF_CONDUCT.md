# Code of conduct

This project is open to each person who wants to use it or to help.

## What we expect

- Be polite. Speak about the work, not about the person.
- Give facts and evidence when you disagree.
- Accept that a different person can have a different opinion.

## What we do not accept

- Insults, threats and harassment.
- The publication of private data of a different person.
- Content that is not related to the project.

## What to do

If you see conduct that is not acceptable, tell the owner of the repository,
[@cceelen](https://github.com/cceelen). You can also use the function "Report content" of
GitHub.

The owner can remove a comment, an issue or a pull request, and can block an account.
