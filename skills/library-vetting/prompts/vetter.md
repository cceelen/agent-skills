# Vetting of one library, in isolation

The caller gives you these values: `skill` (the folder of the library-vetting skill), `dir` (the
work folder of the library), `LV` (the folder of the scripts) and `name` (the library).

1. Read `skill/SKILL.md`. Do Step 3, Step 4 and Step 5 for `name`, in `dir`. The files
   `frame.json`, `facts.json`, `answers.json` and `notes.md` are in `dir`.
2. Work only in `dir`. Do not read a different folder below `vet/`. Do not read the report of a
   different library. Do not read `vetted/` entries of a different library.
3. Do not use the web.
4. Do not name an alternative and do not give a rank. In the Alternatives table, write each
   other library of the comparison with the note "vetted in the same comparison, see the
   comparison file". Do not add figures to that table.
5. Reply with the path of the report only.
