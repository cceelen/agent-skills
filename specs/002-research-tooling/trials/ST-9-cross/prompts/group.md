The file patterns.md holds lines from four reports. Each report is about one file of a different project, and it gives the patterns that a reader found in that project. A pattern is a way to arrange the work that a different project can use again. Two readers can give the same pattern different names.

Put the lines that describe the same pattern into one group. Write the file groups.md with one table and no other text:

`| Group | Pattern | Lines |`

- Group: `G-01`, `G-02`, and so on.
- Pattern: a name of five words or less, and no product name.
- Lines: the identifiers of the lines of the group, with a comma between two identifiers.

Put each line into one group, and into one group only. A line that describes a pattern that no other line describes is a group of one line. Do not put two different patterns into one group to make the table short. Do not change patterns.md.
